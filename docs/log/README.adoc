= Session log
:toc:

This directory holds dated records of how the repository's claims were checked.

`CHANGELOG.md` records *what shipped*. It is the wrong instrument for recording that
a shipped sentence miscounted itself, that a commit carried the wrong author's name,
or that a page which passes every automated gate has still never been opened by a
human. Those facts matter to anyone citing this work, and they have nowhere else to
live.

== Naming

`YYYY-MM-DD-topic-slug.adoc`, one file per working session that produced something
worth checking.

== The rule that keeps this honest

*A log entry records how a claim was checked, and is never edited after its date.*

If a later session finds an entry wrong, it writes a new entry saying so and links
back. Editing a dated record in place destroys the only thing it was for.

Corollary, learned the hard way on 2026-09-14: every sentence of the form
"X is currently Y" carries its own date inline, because a record that silently goes
stale is worse than no record — it reads as current.
