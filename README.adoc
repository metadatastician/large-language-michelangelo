= large-language-michelangelo
:toc: preamble
:experimental:

_"I saw the angel in the marble and carved until I set him free."_ — attributed to Michelangelo

One form, two metaphysics. A single-file interactive demonstration that
generation-by-removal and generation-by-addition are the same act read in
opposite directions.

== Live

* GitHub Pages: https://metadatastician.github.io/large-language-michelangelo/
* Claude artifact: https://claude.ai/code/artifact/38d095d3-4957-415c-9ac0-4ff2d3ad2773

== What it shows

Two synced 3-D panes, one shared timeline, one deterministic form definition
(seeded PRNG → form geometry → voxel raster, 29,160 cells). A picker offers
five forms — tree, torus knot, letter M, chess rook, castle — all consumed
by the same machinery; only each form's `fill()` differs.

The Sculptor (left)::
Begins with a solid marble block that already contains the form. The only
operation ever applied is *remove* — tens of thousands of chisel strokes in
an outside-in wavefront, chips falling and settling into a rubble ring. An
X-ray toggle ghosts the block to show the form waiting inside before a
single stroke has landed. Ledger: `N removals · 0 additions`. Epigraph:
_per forza di levare_, Michelangelo's own phrase for sculpture by taking
away (1549 letter to Benedetto Varchi).

The Gardener (right)::
Begins with bare ground and a rulebook (_per via di porre_). The only
operation is *add* — the form's voxels placed in its own growth order
(root to crown, along the knot, course upon course), while the rendering
bootstraps its own colour depth as it matures: one bit, then greys, then
four colours, then full RGB — with the palette derived from the chosen
form's luminance quartiles. Ledger: `0 removals · N additions`.

The invariant::
Both panes consume the identical voxel set. Their final frames are the same
form; only the temporal order of operations differs. The page states the
arithmetic (for the default tree: 2,639 + 26,521 = 29,160) and *re-derives
it*: a verifier re-checks disjointness, completeness and convergence from
the live buffers on every build, and renders the verdict under the timeline.

The instruments::
Under each pane, a live readout of the actual render algebra — the Sculptor's
frame is `draw(marble[0…N−k]) ∪ draw(form[ALL])` (the form term present and
occluded from frame 0), the Gardener's is `draw(form[0…k])` with no other
term. Engine-reported triangle counts fall on one side and rise on the other;
an operation tape streams each addressed stroke and voxel. Sceptics get
read-only live counts at `window.llmProof` in the console, and
`llmProof.verify()` re-runs the invariant checks on demand.

== Why it exists

The project began as a challenge prompt — "you are the Michelangelo of LLMs;
generate an image by *removing* from a block, never adding" — which roughly
ten different LLMs declared "fundamentally, mathematically impossible for any
LLM." The verdict encoded here is that they were wrong about the mathematics
and right only about a narrow reading of token streams:

* Deterministic diffusion sampling (DDIM/ODE flow) means the noise block
  uniquely determines the image — the statue really is already in the marble.
* Autoregressive generation is monotone *subtraction in possibility-space*:
  every token discards futures.
* Additive-from-nothing is the picture nothing implements — a prior always
  exists somewhere: a noise block, a distribution, or a rulebook plus a seed.
  The Gardener relocates the prior into the rules; the Sculptor leaves it in
  the block. Neither creates ex nihilo.

Behind the toy sits a research itch: procedural pathways make revisions
*addressable and diffable* (remove stroke 12,004; re-order the canopy),
where chat-loop image revision is basin-anchored and unverifiable. Two
pathways that provably converge give you a cross-check that a single
pathway cannot.

== Running locally

Open `index.html` in a browser. The only external dependencies are Three.js
0.160.0 (pinned, cdnjs) and Google Fonts; everything else is inline.
Honours `prefers-reduced-motion` by parking the timeline at a static
mid-carve frame.
